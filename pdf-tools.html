How to use KAGZI PDF tools

  1. Open the PDF workspace.
  2. Select the relevant tool and choose your PDF or image files.
  3. Review the options and start processing.
  4. Download the output and check it before sharing or submitting.

Privacy note: The PDF tools on the homepage process selected files locally in your browser as described beside each tool. Files are not uploaded to KAGZI by those local tools. Some libraries are loaded from public CDNs. The PDF Editor processes files locally in your browser; server processing is not currently configured. Keep an original copy of important documents.

Frequently asked questions

Can I merge PDF files online for free?

KAGZI provides a browser-based PDF merge tool. Open the workspace, select two or more PDF files and download the combined file.

Can I convert JPG to PDF?

Yes. Use the Images to PDF tool to combine selected JPG or PNG images into one PDF.

Does PDF compression preserve selectable text?

The current compression tool creates an image-based PDF. Text may no longer be selectable, so review the result and keep your original file.

Are my selected PDF files uploaded?

The local PDF tools process files in the browser tab and do not upload them to KAGZI. Check the privacy note shown with each tool before use.
