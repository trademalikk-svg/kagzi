## Targeting rules

1. Keep one primary search intent per landing page. Do not repeat the same title and primary phrase across multiple pages.
2. The two language versions should be genuine translations/adaptations with reciprocal hreflang links, not duplicate blocks.
3. Subject pages remain the destination for subject-specific searches; the Education PDF landing pages act as discovery hubs and link to those existing books.
4. Do not claim official exam affiliation, complete syllabus coverage, verified previous-year questions, guaranteed results or government endorsement.
5. Keep public informational landing pages crawlable. Authenticated workspaces and account-only libraries should not be added to the public sitemap.
6. Review Search Console data every 14 days. Prioritise queries with meaningful impressions and average position 5–20; improve the matching page rather than creating a near-duplicate URL.
7. Treat ranking improvements as an outcome to measure, not a guaranteed result. Search Console clicks and impressions must come from Google's actual reporting and cannot be generated by page metadata alone.

## Search Console measurement checklist

- Search type: Web
- Compare: last 28 days vs previous 28 days once sufficient data exists
- Dimensions: Queries, Pages, Countries, Devices
- Metrics: Clicks, Impressions, CTR, Average position
- Filter branded queries separately from non-branded queries
- Inspect page/query pairs before changing titles; retain the page's actual service intent
