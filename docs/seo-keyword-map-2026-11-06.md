# KAGZI SEO keyword map — 6 November 2026

## Scope and method
This is a qualitative SERP-intent map for the current KAGZI site. No search-volume, CPC, difficulty, or ranking claims are made because no verified Google Search Console export or keyword-planner dataset was supplied. Recheck actual impressions, clicks, CTR and average position in the connected Search Console property before prioritising scale.

## Priority clusters

### 1. Uttar Pradesh citizen-service guidance
- Primary: UP e-District services; UP e-Sathi online services
- Secondary: income certificate apply online UP; caste certificate UP; domicile/residence certificate UP; आय प्रमाणपत्र ऑनलाइन उत्तर प्रदेश; जाति प्रमाणपत्र कैसे बनवाएं; निवास प्रमाणपत्र ऑनलाइन; सरकारी दस्तावेज़ चेकलिस्ट
- Intent: informational / navigational; users need current official procedure, eligibility and document checklist.
- Best landing page: /jan-seva.html
- Supporting page: /gov-documents.html
- Content angle: plain-Hindi steps, document checklist, district/state caveat, date checked, direct official portal link. Clearly state KAGZI is not a government agency and does not issue certificates.
- Evidence: National Government Services Portal describes UP e-District for caste, income, residence, birth and death certificates; Prayagraj Division's UP government page describes e-Sathi application and certificate download. Sources: https://services.india.gov.in/service/detail/uttar-pradesh-e-district-services and https://prayagrajdivision.nic.in/service/online-citizen-services/

### 2. Hindi + English government document directory
- Primary: government document checklist India; सरकारी दस्तावेज़; government services Uttar Pradesh
- Secondary: birth certificate process; ration card correction UP; old age pension UP; widow pension UP; PM Kisan registration; UP Bhulekh khatauni; voter ID correction; driving licence services
- Intent: informational / navigational.
- Best landing page: /gov-documents.html
- Content angle: searchable service directory with short summaries and links to official sources. Avoid copying or hosting government forms unless reuse rights are documented.

### 3. PDF and image utilities (existing product cluster; maintain only if these tools are live on the current build)
- Primary: merge PDF online; compress PDF; JPG to PDF; PDF tools online
- Secondary: split PDF online; image to PDF; PDF OCR Hindi; photo resize online
- Intent: transactional/tool use.
- Best landing pages should be the dedicated tool pages, not the Jan Seva homepage.
- Important: do not promise unlimited file size, server privacy, OCR accuracy or offline processing unless the live implementation verifies it.

### 4. Passport / ID photo tool (existing product cluster; verify route is live before SEO push)
- Primary: passport size photo maker online; passport photo 35x45 mm
- Secondary: 3.5x4.5 cm photo; 413x531 px photo; passport photo resize; photo size for online form; passport photo background
- Intent: transactional/tool use.
- Best landing page: /passport-size-photo-maker.html
- Content angle: explain common dimensions and that each issuing authority/form can specify different pixel, KB, background and framing rules. Never imply one preset fits every application.
- SERP observations: several currently visible specialist tools target 35x45 mm / 413x531 px, privacy/local processing, and print sheets. This indicates a competitive tool-intent SERP, not verified search volume. Recheck actual GSC query data.

## On-page rules
1. One clear primary intent per URL; do not put all keyword clusters into the homepage title.
2. Unique title and meta description matching the visible page content.
3. One descriptive H1, logical H2s, useful internal links, descriptive anchor text.
4. Add FAQ only when the answer is genuinely present on the page; use structured data only for visible, accurate content.
5. Keep official source links, last-reviewed date, and a clear independent-service disclaimer on government information pages.
6. Keep sitemap limited to canonical, indexable, live HTML pages; exclude login, API, test and duplicate routes.
7. Avoid keyword stuffing, doorway pages, fake location pages and unverified claims.

## Measurement plan
- In Google Search Console, select the verified KAGZI domain/property and export the last 28 days and previous 28 days.
- Group queries by the clusters above; compare impressions, clicks, CTR and average position.
- Improve pages with impressions but low CTR first; improve content for queries ranking around positions 8–30 next.
- Reassess after 28 days. Do not report a ranking improvement until Search Console confirms it.
