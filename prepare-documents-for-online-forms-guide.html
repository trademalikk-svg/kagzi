How to Prepare Photos and Documents for Online Forms | KAGZI

Online application portals often specify file types, image dimensions, size limits and naming rules. Use this checklist to prepare files carefully, while always following the exact instructions on the official portal.

Feature note: Follow the current controls and privacy notice shown inside the tool. Keep an original copy of important files.

1. Read the portal's instructions first

Before editing anything, note the portal's current requirements for each upload field. Record the accepted formats, maximum file size, minimum or exact dimensions, colour/background rules, page count and whether a signature or self-attestation is required. Requirements can differ between applications and can change over time.

Important: There is no single photo size or document format that works for every form. The receiving portal's own instructions take priority over any general guide or preset.

2. Prepare document scans

  • Capture every page clearly and include all required edges.
  • Keep pages upright and in the correct sequence.
  • Check that names, dates, seals, signatures and numbers are readable.
  • Use PDF or image format only if the portal accepts it.
  • When combining pages, verify that the final PDF includes only the required pages.

Use the phone scanning guide for capture tips and the PDF page extraction guide when only selected pages are required.

3. Prepare the photograph

Use the portal's stated width, height, aspect ratio, file type, file-size limit and background requirements. A passport-photo preset can help create a starting dimension, but it does not certify that the image meets a particular authority's face-position, background or identity-photo rules.

KAGZI Photo Tools can resize, crop, convert and compress supported images. Check the actual exported file size rather than assuming a chosen quality setting will meet a specific KB limit.

4. Name files clearly and protect your information

  • Use simple file names such as photo.jpg, identity-document.pdf or signature.png when the portal does not prescribe a name.
  • Avoid spaces or special characters if the portal's upload instructions prohibit them.
  • Do not share OTPs, passwords or full identity details with anyone offering upload help.
  • Use your own trusted device and network for sensitive documents.
  • Keep a secure copy of the original file and the final submitted version.

5. Final upload checklist

  1. Correct applicant and application category selected.
  2. Correct file attached to each field.
  3. File opens and is not password-protected unless the portal allows it.
  4. Size, format and dimensions match the portal's current rules.
  5. All pages and important text are readable.
  6. Preview the uploaded file before final submission, if the portal offers a preview.
  7. Save the acknowledgement or reference number after submission.

Online Form के लिए फोटो और दस्तावेज़ कैसे तैयार करें?

किसी भी online form में फोटो या दस्तावेज़ upload करने से पहले उसी portal की वर्तमान instructions पढ़ें। हर आवेदन के नियम अलग हो सकते हैं। कोई एक photo size, PDF format या KB limit सभी forms के लिए सही नहीं होती।

  • सभी पेज साफ और पूरे दिखाई दें।
  • नाम, तारीख, हस्ताक्षर, मुहर और नंबर पढ़ने योग्य हों।
  • पेज सही क्रम में हों और केवल जरूरी पेज शामिल हों।
  • Portal जिस format को स्वीकार करता है, वही चुनें।

फोटो की जाँच

Portal में बताए गए exact width, height, background, file type और KB limit का पालन करें। KAGZI Photo Tools से photo resize, crop, convert और compress किया जा सकता है, लेकिन preset किसी सरकारी विभाग या संस्था की acceptance की guarantee नहीं देता।

Upload से पहले अंतिम checklist

  1. सही applicant और application चुना है।
  2. हर field में सही file लगी है।

सुरक्षा: OTP, password या अनावश्यक पहचान संबंधी जानकारी किसी अनजान व्यक्ति को न दें। संवेदनशील दस्तावेज़ अपने भरोसेमंद device से ही upload करें।

Frequently asked questions

Can I use one passport photo size for every online form?

No. Each portal or authority may specify different dimensions, background, file type and file-size requirements. Follow the current instructions for that application.

How can I check a photo's KB size?

After exporting from a photo tool, check the actual file properties on your device or the upload portal. Do not rely only on a quality slider.

Should I combine all supporting documents into one PDF?

Only if the portal requests one combined PDF. If it provides separate upload fields, follow those fields and accepted formats.

Does KAGZI verify government application documents?

No. KAGZI provides document utilities and informational guides; it is not a government department and does not certify documents or guarantee application acceptance.
